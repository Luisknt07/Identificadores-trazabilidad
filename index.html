Identificador 1 de 3

Code 128

Es un código de barras lineal de alta densidad. Resulta apropiado para identificadores internos que combinan letras, números y otros caracteres, como UPEC-ALM-ALI-P001-L03.

Cuándo usarlo

  • Etiquetas de cajas, pallets y ubicaciones.
  • Inventario y activos internos.
  • Números de serie, órdenes o lotes alfanuméricos.
  • Procesos logísticos que no pasan por caja comercial.

Ventajas y límites

  • Codifica mucha información en poco ancho.
  • No exige que el valor sea únicamente numérico.
  • Necesita contraste, altura y zonas silenciosas laterales.
  • No debe confundirse con GS1-128, que utiliza FNC1 e identificadores de aplicación GS1.

En LogiTrace: úsalo como opción predeterminada para IDs propios de producto y etiquetas internas de almacén.

Identificador 2 de 3

EAN-13

Representa un GTIN-13 mediante 13 dígitos. El último es un dígito de control calculado a partir de los 12 anteriores y ayuda a detectar errores de lectura.

Cuándo usarlo

  • Productos destinados al punto de venta minorista.
  • Artículos que necesitan interoperabilidad comercial.
  • Catálogos donde cada presentación tiene su propio GTIN.

Ventajas y límites

  • Es reconocido ampliamente por sistemas de punto de venta.
  • Su estructura es estrictamente numérica.
  • No guarda descripción, precio, lote ni fecha dentro del símbolo.
  • Para uso comercial, el número debe proceder de una asignación GS1.

Importante: el generador puede crear un EAN-13 técnicamente válido para demostración interna. Eso no lo convierte en un GTIN oficialmente asignado ni autoriza su uso comercial.

Identificador 3 de 4

Código QR

Es un símbolo bidimensional que almacena datos horizontal y verticalmente. Puede leerse en cualquier orientación y ofrece distintos niveles de corrección de errores.

Cuándo usarlo

  • Abrir la trazabilidad desde un teléfono.
  • Codificar un ID, URL, texto o JSON estructurado.
  • Etiquetas con poco espacio y más información.
  • Procesos donde el usuario utiliza una cámara.

Ventajas y límites

  • Admite mucha más información que un código lineal.
  • Puede recuperar datos cuando una parte está dañada.
  • Cuantos más datos contiene, más módulos y tamaño necesita.
  • Un QR común no cifra ni vuelve privados los datos codificados.

Privacidad: codifica solamente el ID o una URL controlada. No incluyas contraseñas, claves, datos personales ni información confidencial directamente en el QR.

Identificador 4 de 4

RFID

RFID identifica y rastrea objetos mediante ondas de radio. A diferencia de los códigos ópticos, no necesita que la etiqueta esté visible frente a una cámara y puede detectar varias etiquetas dentro del campo de lectura.

Cuándo usarlo

  • Inventarios rápidos de muchas unidades.
  • Portales de entrada y salida de almacén.
  • Seguimiento de pallets, activos, textiles o herramientas.
  • Procesos donde el polvo, la orientación o la falta de visión dificultan el escaneo óptico.

Qué necesita un sistema real

  • Etiqueta RFID con chip y antena.
  • Lector o interrogador compatible con la frecuencia y protocolo.
  • Una o más antenas correctamente ubicadas.
  • Middleware o backend que filtre lecturas y las vincule con LogiTrace.

International Standard Music Number

ISMN identifica partituras y música notada

Consta de 13 dígitos, comienza con 979-0 y termina con un dígito de control. El número oficial debe ser asignado por una agencia ISMN; el generador valida la estructura, pero no asigna derechos ni registros.

  • Prefijo de música: 979-0.
  • Elementos de registrante y publicación.
  • Control módulo 10 compatible con EAN-13.

Resolución de dudas

Preguntas frecuentes

¿Code 128 y GS1-128 son lo mismo?

No. GS1-128 utiliza la simbología Code 128, pero añade FNC1 y una estructura de identificadores de aplicación GS1 para interpretar campos como GTIN, lote o vencimiento.

¿Puedo vender un producto con cualquier EAN-13 generado?

No. Para comercialización debes utilizar un GTIN asignado de acuerdo con las reglas de GS1. El generador interno sirve para pruebas o docencia cuando no se afirma que sea un GTIN oficial.

¿Un QR protege la información que contiene?

No por sí solo. Un QR común representa datos; cualquier lector compatible puede mostrarlos. La seguridad debe aplicarse en el sistema o enlace de destino.

¿El navegador puede leer una etiqueta RFID real?

No directamente. El módulo actual es una simulación académica. Para RFID real se necesita un lector compatible y un servicio que comunique el hardware con la API de LogiTrace.

¿Puedo inventar un número ISMN?

Puedes generar ejemplos estructuralmente válidos para pruebas, pero un ISMN oficial debe ser asignado por una agencia ISMN al registrante y a la publicación correspondiente.

¿Por qué la cámara no lee una etiqueta?

Revisa permisos, enfoque, iluminación, contraste, tamaño, márgenes y que el código no esté deformado. Prueba también con la carga de imagen para aislar el problema.
